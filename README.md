# Agendador Descargas — PWA

Arquivos prontos para publicar no GitHub Pages, Vercel ou outro host HTTPS.

Arquivos:
- index.html — aplicativo
- manifest.json — configuração PWA
- sw.js — service worker/offline shell
- icon.svg — ícone

Observação:
A sincronização entre aparelhos continua dependendo da configuração do Supabase no próprio aplicativo. O PWA, sozinho, não cria sincronização entre dispositivos.
