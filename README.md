# Agendador Descargas — PWA

1. Envie todos os arquivos desta pasta para um repositório do GitHub.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch principal e a pasta `/ (root)**.
5. Abra a URL publicada em HTTPS no celular ou PC.
6. No navegador, use **Adicionar à tela inicial / Instalar app**.

### Sincronização entre aparelhos
A sincronização dos dados continua dependendo da configuração do Supabase dentro do botão **Config** do aplicativo. O PWA sozinho não cria sincronização entre dispositivos.
